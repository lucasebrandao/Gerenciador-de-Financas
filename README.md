# Gerenciador de Finanças

Projeto desenvolvido em Python para praticar lógica de programação, organização de código e manipulação de dados.

O programa permite cadastrar transações financeiras, consultar o saldo e manter os dados salvos mesmo após fechar a aplicação utilizando arquivos JSON.

## Funcionalidades

- Adicionar transações;
- Visualizar transações cadastradas;
- Calcular saldo;
- Salvar dados em JSON;
- Carregar dados automaticamente ao iniciar o programa.

## Tecnologias utilizadas

- Python
- JSON
- Git
- GitHub

## Estrutura do projeto

- `main.py` → responsável pelo menu e controle principal da aplicação.
- `transacoes.py` → contém as funções relacionadas ao gerenciamento das transações.
- `dados.json` → arquivo utilizado para armazenar os dados.

## Como executar

1. Clone este repositório.
2. Execute o arquivo `main.py`.
3. Utilize o menu para interagir com a aplicação.
